2.2.2 plotly交互式图形鉴别异常点

Code 
library(plotly)
pic <- ggplot(happy_data2,aes(x=wealth,y=happiness,group=country))+
  geom_point()
ggplotly(pic)

Code 
pic <- ggplot(happy_data3,aes(x=year,y=wealth,color=country))+
  geom_point()
Code 
ggplotly(pic)
